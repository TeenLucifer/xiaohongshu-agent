# 018 Agent Skills Suite Acceptance

1. 小红书选题、对标与方向调研由 runtime 的简短原则定义，默认只搜索和分析，不默认下载、不落盘
2. `xhs-explore` 在搜索/调研回复中附带可点击的原始帖子链接，并默认使用带 `xsec_token` 的完整详情 URL
3. `pattern-summary` 默认消费当前全部剩余帖子
4. `copy-rewrite` 默认消费当前全部剩余帖子与总结结果
5. `image-analysis` 与 `image-generation` 只读取各自 skill 目录下的 `config.json`
6. skill 文档中不再把 `selected_posts.json` 作为正式输入
